Project description

Customer churn costs telecom operators far more than acquiring new subscribers. This project predicts which customers are likely to leave, explains why, and suggests retention actions, all through an interactive dashboard connected to real trained models.

Every number and chart in this app is computed from the IBM Telco Customer Churn dataset or from the models trained on it. Nothing is hard-coded.

Model architecture
Raw features (19)
 └─ ColumnTransformer
   ├─ numeric → Imputer → StandardScaler
   └─ categorical → Imputer → OneHotEncoder
     └─ Classifier → churn probability
       ├─ Random Forest (400 trees, depth 12)
       └─ XGBoost (300 trees, depth 3, lr 0.05)
         └─ threshold → Low / Medium / High risk
Risk bands: Low < 30%, Medium 30–60%, High ≥ 60% churn probability.
